{% comment %} Confirmation dialog for cancelling one order. Included once per cancellable order, always inside the page-level {% block modals %} in base.html so every dialog is a direct child of . That placement matters: a Bootstrap modal is position:fixed, and fixed elements are positioned against their nearest ancestor with a CSS transform (or will-change: transform). The order list keeps each card inside a [data-reveal] entrance wrapper that carries both, and hovering a card transforms it too - a modal rendered inside those would be re-anchored to the card/list instead of the viewport. The result is the page darkening behind the backdrop while the dialog itself is misplaced or off-screen, with the buttons underneath unclickable. Body level keeps the dialog centred and usable. The id carries the order number so several of these can share a page. {% endcomment %}
